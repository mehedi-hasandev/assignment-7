# 🛒 বাজার দর (BazarDor)

বাজার দর is a modern web application designed to track the daily prices of essential commodities in Bangladesh. It helps users make informed purchasing decisions by comparing market prices and tracking daily price fluctuations.

## Technologies Used
- Next.js (App Router, JavaScript)
- Tailwind CSS & DaisyUI
- BetterAuth (Authentication)
- React Hot Toast

## Key Features
1. **Live Price Tracking**: Infinite marquee ticker showing real-time commodity prices and daily percentage changes.
2. **Market Trends**: Dedicated sections highlighting the top products that have increased (▲) or decreased (▼) in price today.
3. **Smart Sorting**: Category pages feature a robust sorting mechanism capable of accurately parsing and sorting Bengali numerals.
4. **Detailed Analytics**: Product detail pages provide minimum, maximum, and average price summaries across different local markets.
5. **Secure Profiles**: Protected routes and profile management allowing users to update their personal information seamlessly.
